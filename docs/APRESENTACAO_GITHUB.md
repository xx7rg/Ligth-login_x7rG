## Texto de apresentação

O **LIGHT Login Experience** explora uma forma mais sensorial de apresentar uma
tela de acesso. O abajur funciona como parte da navegação: ao interagir com o
cordão, o usuário controla a iluminação, a visibilidade do formulário, o
movimento e a resposta sonora da cena.

Construído com Next.js, React, TypeScript, CSS e Web Audio API, o projeto combina
design visual, interação por ponteiro e toque, responsividade e acessibilidade.
A aplicação é exportada como site estático e publicada automaticamente no
GitHub Pages.
